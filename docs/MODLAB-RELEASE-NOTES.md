# ModLab 0.1.0-alpha.2

**ModLab is an all-in-one gameplay and quality-of-life mod suite for Minecraft Dungeons II.**

## Download

Download **ModLab-Setup-0.1.0-alpha.2.exe**. Close the game, select your Steam game folder,
click **Install / Update**, launch through Steam and press **F10**. Everything needed
is included in this one installer.

ModLab-0.1.0-alpha.2.zip contains the same EXE plus instructions, licenses and validation
notes. Choose the EXE or ZIP; you do not need both.

## Features

- **Berserker:** persistent Rage/Mastery progression, talent branches, saved loadouts,
  War Cry, Rampage, Ascension and animated buffs with timers.
- **Soul Storm:** endless region farming, independent generator/completion chest rolls,
  expanded native Soul Storm loot pools, generator map markers and travel, shield removal.
- **Boss Rush / Roulette:** fixed or shuffled boss sequences with Enchantment Book rewards.
- **Dungeon / Rift Directors:** additional miniboss encounters while exploring.
- **Smart Filter + Auto Sell:** rarity decisions, optional Power protection, item
  protection and a preview of sale decisions and rewards.
- **Wanted Items:** protect and track specific gear, rarity and Power targets.
- **Enchant Workshop, DPS meter, run reports and expanded wallet.**
- **Quality of life:** pickup, nearby chest opening, fast travel, arrows, movement,
  attack speed, XP/currency modifiers and additional drop chance.
- **Experimental Headhunter:** temporary theft of supported Soul-Enchanted powers.

[Read the detailed feature guide](https://github.com/falorfrozen-cmd/ModLab#feature-overview).

## This update

The public project and installer now use **ModLab** as the product name. The GitHub
landing page explains every feature and points directly to the single player installer.
The eight runtime files are unchanged from alpha.1; this is a branding/documentation update.

Fresh installation, update, adoption of existing packages, removal, partial-move rollback
and invalid-input rejection were retested with the compiled EXE. Older standalone
installer downloads have been retired from the public player release list.

## Compatibility

Experimental alpha for **Windows x64, Steam build 25754144 / game 1.1.2.0**. Primarily
tested offline. Other builds, launchers and multiplayer are unverified. Headhunter
remains experimental; direct final Dungeon/Rift ambush travel is unavailable.

The intermittent **0xC0000005 on game shutdown** remains open; this update does not
claim to fix it. Setup is unsigned. Verify downloads using SHA256SUMS.txt.

Use the same ModLab Setup for updates and removal. Character saves and settings are
not changed by Setup. Keep ModLabBackups if you need to restore the earlier installation.
